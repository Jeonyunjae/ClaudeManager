## 피드백

### 1. 웹앱 → Claude CLI 양방향 제어 기능 누락
- 요구사항에 "tmux + node-pty + Hooks (stdin/stdout 완전 제어)"가 명시되어 있음
- 기능 목록에 **웹에서 CLI로 명령을 보내는 기능**(양방향 터미널 제어)이 빠져 있음
- 인스턴스 상세 뷰(F015)에 xterm.js 터미널 표시만 있고, 입력(stdin) 전송 기능이 없음

### 2. 감사 로그(Audit Trail) 기능 누락
- 승인 이력(F025)은 있지만, 시스템 전체 행동 감사 로그가 없음
- 누가(대표) 언제 무엇을 지시/승인/반려했는지 전체 이력
- 에이전트 행동 로그 (디버깅 + 사후 분석용)

### 3. 대표 → Main 지시 인터페이스 누락
- Human-in-the-Loop에서 "승인 처리"만 있음
- 대표가 **능동적으로 Main에게 새로운 지시를 내리는 채팅/명령 UI**가 기능 목록에 없음
- 승인 외에도 "이 프로젝트 우선순위 올려" 같은 능동적 지시가 가능해야 함

### 4. PRD에 기술 스택 테이블 누락
- 요구사항의 기술 스택 테이블(Next.js, Node.js, SQLite, LiteLLM 등)이 PRD에 반영되지 않음
- PRD에 기술 스택 섹션 추가 필요

### 5. DB 저장 데이터 명세 미반영
- 요구사항에 추가한 "DB 저장 데이터 및 역할 분담" 9개 카테고리가 PRD에 반영되지 않음
- 에이전트/세션, 의사결정/승인, 비용/토큰, 알림, 오류/재시도, API 키, 진행 상태, Skill 메타데이터, 시스템 헬스

### 6. 인프라/배포 기능 누락
- Vercel 배포, PM2+launchd 설정 등 인프라 셋업 관련 기능이 기능 목록에 없음
- 개발 환경 구성, 프로세스 관리 설정 등도 기능으로 포함 필요

### 7. 메타버스 스타일 UI 컨셉 추가 요청
- 대시보드를 단순한 테이블/차트가 아닌 **메타 공간(가상 오피스)** 으로 구성
- 각 에이전트(Main, Part, Sub, 인스턴스)를 **귀여운 캐릭터**로 시각화
- Part = 부서 공간, Sub = 팀 공간으로 메타 공간 내 구역을 나눠 표현
- 캐릭터들이 해당 공간에서 작업하는 모습으로 진행 상태를 직관적으로 보여줌
- 예: 프로젝트 Part 부서에 팀장 캐릭터(Sub)가 있고, 외주 인력 캐릭터(인스턴스)가 작업 중인 애니메이션
- 승인 대기 시 캐릭터가 대표실 앞에서 기다리는 등 상태를 시각적으로 표현
- 이 컨셉은 컨셉 결정 단계에서 상세화하되, 기획 시 UI 방향성으로 반영 필요

### 8. 설정/환경설정 UI 누락
- 재시도 횟수/간격, 알림 임계값, 비용 한도 등을 **웹에서 설정하는 화면**이 기능 목록에 없음
- Part별 정책(승인, 재시도, 민감도)을 코드가 아닌 UI에서 관리해야 대표가 직접 조정 가능

### 9. 검색/필터링 기능 누락
- 승인 이력, 오류 로그, 비용 내역 등이 쌓이면 검색/필터가 필수
- 기간별, Part별, 상태별 필터링
- 로그 검색 기능

### 10. 데이터 백업/복원 기능 누락
- SQLite DB + `.orchestrator/` 파일의 백업 전략
- 자동 백업 주기 설정, 복원 절차
- Mac Mini 이전 시에도 필수

### 11. 동시 에이전트 리소스 관리 누락
- Mac 리소스 한계 상 동시 실행 에이전트 수 상한 설정
- 상한 초과 시 큐잉 또는 대표에게 확인 요청
- CPU/메모리 기반 자동 제한 고려

### 12. 온보딩/초기 설정 마법사 (P2 가능)
- 최초 실행 시 환경변수, API 키, Skill 경로 등을 가이드하는 설정 위자드
- Phase 2로 넘겨도 무방하나 기능 목록에는 포함 필요
