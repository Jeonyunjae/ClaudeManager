## 1. 레퍼런스 디자인 핵심 해부

### 1-1. 전체 구조 (Page Anatomy)

```
┌─────────────────────────────────────────────────────┐
│  Top Nav: 로고 + 탭 네비게이션 + 프로필 아이콘       │
├──────┬──────────────────────────────────────────────┤
│      │  Avatar Bar (원형 프로필 사진 + 숫자 뱃지)      │
│ Icon │──────────────────────────────────────────────│
│ Side │  Column Flow: 4개 컬럼 + 카드 + 커넥션 라인    │
│ bar  │  (Case Allocation → Issue ID → Tech Res → New)│
│      │──────────────────────────────────────────────│
│      │  Bottom Section:                              │
│      │  [Suggested Knowledge 테이블] [Donut Chart]    │
└──────┴──────────────────────────────────────────────┘
```

### 1-2. 컬러 시스템

| 요소 | SugarCRM 값 | 특징 |
|------|-------------|------|
| **배경** | `#F0F2F5` (연회색) | 차분하고 전문적인 느낌, 카드와 자연스럽게 분리 |
| **카드 배경** | `#FFFFFF` | 순백색, 미세한 그림자로 부유감 |
| **하이라이트 카드** | `#10141A` (거의 검정) | 현재 활성 단계를 강조 — **핵심 차별점** |
| **텍스트 (주)** | `#10141A` | 진한 다크, 가독성 최우선 |
| **텍스트 (보조)** | `#9CA3AF` | 연한 그레이 |
| **액센트 핑크** | `#E8A2DB` ~ `#C84968` | 아바타 뱃지, 차트 세그먼트에 사용 |
| **액센트 블루** | `#5B9BF7` 계열 | 링크, 활성 상태 |
| **커넥션 라인** | `#D1D5DB` (연그레이) | 얇고 섬세, 화살표 포함 |

### 1-3. 타이포그래피

- **디스플레이 폰트**: Lufga (세리프 스타일, 제목에만 사용)
- **본문**: Inter/System sans-serif
- **크기 계층**: 제목 20-24px / 카드 타이틀 13-14px / 캡션 10-11px
- **자간**: 제목에 약간의 트래킹, 본문은 기본값

### 1-4. 카드 디자인 (핵심)

#### 일반 카드 (White Card)
```
┌──────────────────────────┐
│ [○ 아바타 40px]  텍스트    │  ← 왼쪽 원형 아바타 + 오른쪽 텍스트
│                  2줄 내외  │
│            [✓] [□] [···]  │  ← 우하단 액션 아이콘 (12px, 그레이)
└──────────────────────────┘
```
- **라운드**: 12-16px (부드럽지만 과하지 않음)
- **그림자**: 매우 가벼움 (`0 1px 3px rgba(0,0,0,0.04)`)
- **패딩**: 12-16px
- **아바타**: 실제 사진 또는 이니셜, 항상 원형
- **텍스트**: 1~2줄, 작업 내용 요약
- **액션 아이콘**: 체크(✓), 복사(□), 더보기(···) — 항상 표시(hover가 아님)

#### 하이라이트 카드 (Dark Card)
```
┌──────────────────────────┐  ← bg: #10141A
│ [○ 아바타]  텍스트 (흰색)  │
│            [✓] [□] [···]  │  ← 아이콘도 흰색/연회색
└──────────────────────────┘
```
- 현재 활성/처리중인 작업을 강조
- 텍스트와 아이콘이 흰색으로 반전
- 한 컬럼에 최대 1개

### 1-5. Avatar Bar (상단)

```
[○][○][○][○][○][○][○]  ← 원형 사진 아바타 (36-40px)
 2   3   1              ← 작은 원형 숫자 뱃지 (코럴/핑크/블루)
```
- **아바타 크기**: 36-40px 원형
- **뱃지**: 아바타 우하단에 겹침, 색상으로 상태/역할 구분
- **숫자**: 할당 건수 등
- **간격**: 아바타 간 8-12px
- **배경**: 카드 영역과 동일 라인에 위치 (별도 바가 아님)

### 1-6. 컬럼 레이아웃

- **컬럼 수**: 4개
- **컬럼 배경**: 없음 (투명) — **핵심 차이점. 회색 박스가 아닌 자유 부유 카드**
- **컬럼 라벨**: 하단에 위치, 연한 대문자 텍스트
- **카드 간격**: 세로 12-16px
- **컬럼 간격**: 가로 24-32px

### 1-7. 커넥션 라인

- **스타일**: 얇은 곡선 (1-1.5px, 연회색)
- **화살표**: 작은 삼각형 마커 (끝점)
- **곡률**: 완만한 베지어 커브
- **배경과 조화**: 라인이 눈에 띄지 않되 흐름은 이해 가능

### 1-8. 하단 섹션

#### Suggested Knowledge 테이블
- 깔끔한 테이블 레이아웃
- 각 행: 아이콘 + 제목 + 상태 뱃지 (Completed / In Progress / Not Started)
- 뱃지 색상: 녹색/청색/회색

#### Support Ticket Journey 도넛 차트
- 도넛(원형) 차트, 중앙에 총 건수
- 각 세그먼트별 범례
- 색상: 코럴, 핑크, 라벤더, 연핑크

### 1-9. 좌측 사이드바

- **폭**: 48-56px
- **아이콘**: 단색 라인 아이콘 (20px)
- **활성 표시**: 좌측 3px 바 (accent color)
- **배경**: 흰색 또는 투명

## 2. 현재 ClaudeManager vs SugarCRM 차이점 분석

### 2-1. 구조적 차이

| 요소 | SugarCRM 레퍼런스 | 현재 ClaudeManager | GAP |
|------|-------------------|-------------------|-----|
| **컬럼 배경** | 투명, 카드만 부유 | 회색 박스(`--column-bg`) + border | **큰 차이** — 컬럼 배경 제거 필요 |
| **컬럼 라벨 위치** | 하단에만 | 상단+하단 모두 표시 | 하단만 유지, 상단 제거 |
| **카드 패딩** | 12-16px, 컴팩트 | 14px (`p-3.5`), 적절 | 유사 |
| **하이라이트 카드** | 다크 배경 1개 | 없음 (ring으로만 강조) | **핵심 누락** — 활성 카드 다크 모드 추가 |
| **Avatar Bar** | 사진 아바타 + 숫자 뱃지 | 이니셜 원 + 상태 도트 | 숫자 뱃지 추가, N뱃지→숫자 |
| **카드 그림자** | 거의 없음 (매우 가벼움) | `shadow-card` (적절) | 약간 줄여도 됨 |
| **카드 액션 아이콘** | 항상 표시 | hover시만 표시 | **변경 필요** — 항상 표시 |
| **하단 섹션** | 테이블 + 도넛 차트 | 없음 | **추가 필요** — Knowledge/Statistics |

### 2-2. 컬러 차이

| 토큰 | 현재 값 | 권장 변경 | 이유 |
|------|---------|----------|------|
| `--bg-base` | `#F0F2F5` | 유지 | SugarCRM과 동일 |
| `--column-bg` | `#F7F8FA` | 제거 (투명) | 카드가 직접 base 위에 부유 |
| `--column-border` | `#E2E8F0` | 제거 | 컬럼 경계선 없음 |
| `--connection-line` | `#CBD5E0` | `#D1D5DB` | 약간 더 연하게 |
| `--shadow-card` | 현재 값 | `0 1px 3px rgba(0,0,0,0.04)` | 더 가볍게 |
| `--radius-card` | `16px` | `12px` | 약간 줄임 |

### 2-3. 컴포넌트별 세부 차이

#### FlowColumn.tsx
- **현재**: 회색 배경 + 보더로 감싸진 영역
- **목표**: 배경/보더 없이 투명, 카드만 세로 나열
- **라벨**: 상단 라벨 제거, 하단에만 연한 라벨

#### AgentFlowCard.tsx
- **현재**: 상태 뱃지 (텍스트), 프로그레스 바, hover 액션
- **목표**: 
  - 활성 카드 → 다크 배경 (`#10141A`) + 흰색 텍스트
  - 액션 아이콘 항상 표시
  - 프로그레스 바 → 더 미세하게 또는 제거
  - 상태 뱃지 → 작은 색상 도트만

#### MainCard.tsx
- **현재**: 센터 정렬, 큰 아바타, 상세 정보
- **목표**: 다른 카드와 같은 크기/스타일, 단 primary 색상 강조
  - 왼쪽 아바타 + 오른쪽 텍스트 레이아웃 (센터→좌측 정렬)

#### AgentAvatarBar.tsx
- **현재**: 별도 회색 바 영역 (h-16, border-bottom)
- **목표**: 
  - 바 배경/보더 제거, 콘텐츠와 자연스럽게 연결
  - 숫자 뱃지 추가 (코럴/블루 색상)
  - 상태 도트 → 숫자 뱃지로 교체

   - 중앙: 총 에이전트 수

## 5. 디자인 원칙 (SugarCRM에서 차용)

### P1. "카드가 주인공"
- 배경은 무대, 카드는 배우. 컬럼 경계선과 배경색을 제거하여 카드가 공간 위에 자유롭게 부유하는 느낌.

### P2. "하나만 강조"
- 전체가 밝을 때, 하나의 다크 카드가 시선을 끈다. 현재 가장 주목해야 할 에이전트(활성 작업 중)를 다크 카드로 표시.

### P3. "정보는 요청할 때만"
- 카드에는 최소한의 정보 (이름, 1줄 상태). 상세 정보는 클릭/호버로 확인. 프로그레스 바 같은 보조 정보는 최소화.

### P4. "선은 얇고 조용하게"
- 커넥션 라인은 구조를 이해시키되 시각적으로 우세하지 않음. 1-1.5px, 연회색.

### P5. "일관된 카드 크기"
- Main이든 Sub이든 Instance이든 카드 크기와 스타일은 동일. 역할은 아바타 색상과 위치로 구분.

## 6. 우선순위 정리

| 순위 | 변경 사항 | 효과 |
|------|----------|------|
| **1** | FlowColumn 배경/보더 제거 (투명) | 가장 큰 시각적 차이 해소 |

| **3** | 카드 액션 아이콘 항상 표시 | 인터랙션 힌트 제공 |

| **5** | AvatarBar 배경 제거 + 숫자 뱃지 | 레퍼런스와 일체감 |
| **6** | 하단 테이블 + 도넛 차트 추가 | 대시보드 완성도 |
| **7** | 그림자/라운드 미세 조정 | 폴리싱 |
