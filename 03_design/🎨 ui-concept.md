## 1. 디자인 철학

### 제품 UI 철학 한 문장

**"AI 동료들과 함께하는 공간 -- 따뜻함 속에 정보가 숨 쉬는 UI"**

ClaudeManager의 UI는 "데이터를 읽는 대시보드"가 아니라 "나와 AI 동료들이 함께 있는 메타버스 워크스페이스"이다. 3D 카툰 공간과 데이터 UI가 하나의 비주얼 언어로 통합되어, 나는 숫자를 해석하기 전에 공간의 분위기만으로 조직 상태를 직감한다. 나도 이 공간의 일부로 존재하며, AI 동료들이 내 주변에서 일하는 모습을 통해 "함께 있다"는 느낌을 받는다. Versa Metaverse의 몽환적 파스텔 세계관을 차용하되, 모든 시각 요소는 기능적 의미를 가진다.

### 핵심 디자인 원칙

**1. 공간이 곧 정보다 (Space as Data)**
숫자와 텍스트를 나열하는 대신, 캐릭터의 위치, 모션, 표정, 공간 배치로 정보를 전달한다. 내 주변의 워크스페이스를 둘러보는 것만으로 "지금 조직이 어떤 상태인지"를 즉시 파악할 수 있어야 한다.

**2. 대화가 곧 업무다 (Chat as Workflow)**
모든 프로젝트 지시, 보고, 승인은 채팅 대화 안에서 이루어진다. 복잡한 폼이나 설정 화면이 아니라, Main(비서실장)과의 자연스러운 대화가 주 인터페이스다. 채팅 UI는 단순한 메시지 목록이 아니라 승인 버튼, 옵션 카드, 진행률 표시가 인라인으로 삽입되는 풍부한 인터페이스다.

**3. 따뜻한 전문성 (Warm Professionalism)**
귀엽지만 장난스럽지 않다. 파스텔 톤과 카툰 캐릭터는 정보의 가독성을 해치지 않는 범위 안에서만 존재한다. 함께 일하는 공유 공간의 따뜻한 분위기를 유지하면서도 캐릭터들의 생동감이 업무에 활기를 불어넣는다.

**4. 레이어드 디스클로저 (Layered Disclosure)**
**4. 레이어드 디스클로저 (Layered Disclosure)**
워크스페이스(공유 공간) -> 캐릭터에 접촉(팝업 모달) -> 탭 전환(대화/노트/로그/터미널) 순서로 정보가 깊어진다. 내 캐릭터를 움직여 에이전트에게 다가가 접촉하면 상세 정보가 열리고, 에이전트가 나에게 다가와 접촉하면 승인/리포트/알림이 팝업된다. 원하는 깊이만큼만 정보를 소비한다.
**5. 플랫폼 적응 (Platform Adaptive)**
데스크톱은 3D 워크스페이스 + 채팅의 풍부한 경험, 모바일은 채팅 + 상태 카드의 실용적 경험. 같은 디자인 토큰(색상, 타이포, 간격)을 공유하되 각 플랫폼에 최적화된 레이아웃을 제공한다. 3D 번들은 모바일에서 로딩하지 않는다.

### "하지 않을 것" 목록

- **숫자/텍스트 나열형 대시보드를 메인 화면으로 삼지 않는다** -- 데이터 뷰는 별도 모드로 분리
- **캐릭터가 정보를 가리게 하지 않는다** -- 3D 레이어와 UI 레이어를 명확히 분리
- **하이폴리 3D로 성능을 저하시키지 않는다** -- 캐릭터당 1~2k 폴리곤, Draco 압축
- **과도한 애니메이션으로 집중을 방해하지 않는다** -- 상태 변화 시에만 모션, 평상시는 미니멀 루프
- **모바일에서 데스크톱 경험을 억지로 축소하지 않는다** -- 모바일 전용 경험을 설계
- **다크 모드를 MVP에서 지원하지 않는다** -- Phase 2 야간 워크스페이스 테마로 예정
- **캐릭터 커스터마이징을 제공하지 않는다** -- MVP 범위 밖
- **음성/효과음을 MVP에서 넣지 않는다** -- Phase 2에서 추가

## 2. 비주얼 시스템

### 2.1 색상 시스템

Versa Metaverse 레퍼런스의 파스텔 톤 + 소프트 라이팅 분위기를 웹 UI 전체에 녹인다. 모든 색상은 따뜻하고 부드러운 톤으로 통일하되, 상태 색상은 명확한 구분이 가능하도록 채도를 조절한다.

#### 프라이머리 컬러 (브랜드)

| 토큰 | HEX | 용도 |
|---|---|---|
| `--primary-50` | `#F5F0FF` | 프라이머리 배경, 호버 배경 |
| `--primary-100` | `#EDE5FF` | 선택된 항목 배경 |
| `--primary-200` | `#D4C4FF` | 보더, 디바이더 |
| `--primary-300` | `#B49AFF` | 비활성 상태 |
| `--primary-400` | `#9B7AFF` | 호버 상태 |
| `--primary-500` | `#7C5CFC` | 프라이머리 버튼, 링크, 액센트 (메인) |
| `--primary-600` | `#6344E0` | 프라이머리 버튼 호버 |
| `--primary-700` | `#4D30C0` | 프라이머리 버튼 액티브 |

프라이리 컬러는 라벤더-퍼플 계열로, Versa Metaverse의 몽환적 분위기를 대표한다. 메타버스 워크스페이스의 뜻한 공존감과 AI 기술의 미래지향성을 동시에 표현한다.

#### 세컨더리 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| `--secondary-50` | `#F0FDF9` | 세컨더리 배경 |
| `--secondary-100` | `#D9FBF0` | 세컨더리 호버 |
| `--secondary-300` | `#7EDCBB` | 세컨더리 보더 |
| `--secondary-500` | `#3EC9A0` | 세컨더리 버튼, 민트 포인트 |
| `--secondary-600` | `#2DAD87` | 세컨더리 호버 |

민트-그린 계열로, 파스텔 톤 내에서 프라이머리와 대비를 이루며 보조 액션에 사용한다.

#### 상태 색상

|---|---|---|---|---|---|
| 작업 중 (Active) | `--status-active` | `#5B9BF7` | `#EEF4FF` | `#2563EB` | 정상 진행 중인 에이전트, 프로그레스 |

| 완료 (Complete) | `--status-complete` | `#4ADE80` | `#F0FDF4` | `#16A34A` | 작업 완료, 성공 표시 |
| 대기 (Idle) | `--status-idle` | `#A0AEC0` | `#F7FAFC` | `#718096` | 유휴 상태 에이전트 |

상태 색상은 파스텔 톤 안에서도 구분이 명확하도록 채도를 높인다. 배경색은 카드/배지의 배경으로, 텍스트색은 라벨에 사용한다.

| 토큰 | HEX | 용도 |

| `--bg-elevated` | `#FFFFFF` | 드롭다운, 툴팁 (그림자로 구분) |
| `--bg-overlay` | `rgba(0,0,0,0.4)` | 모달 오버레이 |
| `--bg-sidebar` | `#F8F5F0` | 사이드바, 내비게이션 배경 |
| `--bg-chat` | `#FAF8F5` | 채팅 영역 배경 |
| `--bg-3d-scene` | `#F5EDE3` | 3D 워크스페이스 씬 배경 (연한 베이지) |

배경은 전체적으로 따뜻한 크림/베이지 톤으로 통일한다. 순백(#FFF)은 카드와 모달에만 사용하여 부유감을 준다.

#### Part(부서) 고유 색상

### 2.4 아이콘 스타일

- **스타일**: 라운드 라인 아이콘 (Lucide Icons 사용)
- **선 두께**: 1.5px (기본), 2px (강조)
- **크기 체계**: 16px (인라인), 20px (버튼 내), 24px (내비게이션), 32px (빈 상태)
- **색상**: 텍스트 색상을 따름 (`currentColor`), 상태 아이콘은 상태 색상 사용
- **라운드 캡/조인**: 둥근 선끝과 이음으로 파스텔 톤과 일관된 부드러움 유지
- **커스텀 아이콘**: 에이전트 계층(Main/Part/Sub/인스턴스)용 아이콘은 캐릭터 아바타로 대체

### 2.5 그림자/엘리베이션

Versa 레퍼런스의 소프트 라이팅 느낌을 그림자로 재현한다. 푸른 끼가 살짝 도는 따뜻한 그림자를 사용한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--shadow-xs` | `0 1px 2px rgba(26,21,35,0.04)` | 입력 필드 기본 |
| `--shadow-sm` | `0 2px 4px rgba(26,21,35,0.06)` | 카드, 버튼 호버 |
| `--shadow-md` | `0 4px 12px rgba(26,21,35,0.08)` | 드롭다운, 팝오버 |
| `--shadow-lg` | `0 8px 24px rgba(26,21,35,0.10)` | 모달, 대형 팝업 |
| `--shadow-xl` | `0 16px 48px rgba(26,21,35,0.14)` | 에이전트 팝업 모달 (80%) |
| `--shadow-glow` | `0 0 16px rgba(124,92,252,0.20)` | 승인 대기 강조 글로우 |
| `--shadow-error-glow` | `0 0 16px rgba(240,96,96,0.25)` | 오류 상태 강조 글로우 |

### 2.6 모션/애니메이션

#### 전환 시간

| 토큰 | 시간 | 용도 |
|---|---|---|
| `--duration-instant` | 100ms | 호버, 포커스, 툴팁 |
| `--duration-fast` | 200ms | 버튼 클릭, 토글, 색상 변화 |
| `--duration-normal` | 300ms | 드롭다운, 카드 전환, 탭 전환 |
| `--duration-slow` | 500ms | 페이지 전환, 모달 열기/닫기, 뷰 슬라이드 |

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ease-default` | `cubic-bezier(0.4, 0, 0.2, 1)` | 범용 전환 |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 화면 밖으로 사라질 때 |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | 화면 안으로 등장할 때 |
| `--ease-bounce` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 캐릭터 점프, 배지 등장, 알림 팝 |
| `--ease-spring` | `cubic-bezier(0.22, 1.1, 0.36, 1)` | 모달 열기, 팝업 등장 |

#### 애니메이션 원칙

1. **상태 변화에만 모션을 부여한다** -- 무의미한 장식 애니메이션은 금지
2. **등장은 부드럽게(ease-out), 퇴장은 빠르게(ease-in)** -- 사용자의 시선은 새로 나타나는 요소에 집중
3. **3D 캐릭터 모션은 루프를 최소화한다** -- idle 모션은 3~5초 주기의 미세한 움직임만
4. **승인 대기/오류 상태는 글로우로 시선을 끈다** -- 펄스 애니메이션으로 주기적 강조
5. **모바일에서는 모션을 경량화한다** -- `prefers-reduced-motion` 미디어 쿼리 대응

#### 주요 모션 패턴

| 패턴 | 구현 | 비고 |
|---|---|---|
| 페이지 전환 (페이드) | opacity 0->1, 500ms, ease-out | 로그인 -> 워크스페이스 뷰 |
| 뷰 슬라이드 | translateX, 500ms, ease-default | 워크스페이스 <-> 대보드 전환 |
| 모달 등장 | scale 0.95->1 + opacity, 300ms, ease-spring | 에이전트 접촉 팝업 |
| 캐릭터 이동 | lerp position, 300ms, ease-default | 내 캐릭터/에이전트 이동 |
| 접촉 반응 | scale bounce 1->1.1->1, 200ms, ease-bounce | 릭터 간 접촉 시 |
| 모달 퇴장 | opacity 1->0, 200ms, ease-in | ESC/바깥 클릭 |
| 토스트 등장 | translateY(-8px)->0 + opacity, 300ms, ease-bounce | 알림 토스트 |
| 배지 펄스 | scale 1->1.15->1, 2s, infinite | 승인 대기 배지 |
| 글로우 펄스 | box-shadow opacity 0.2->0.4->0.2, 3s, infinite | 오류/승인 강조 |
| 카드 호버 | translateY(-2px) + shadow 강화, 200ms | 카드 인터랙션 |

## 3. 3D 워크스페이스 비주얼 가이드

### 3.1 3D 씬 구성 원칙

#### 카메라

| 항목 | 설정 | 이유 |
|---|---|---|
| 타입 | `OrthographicCamera` | 아이소메트릭 뷰에 적합, 원근 왜곡 없음 |
| 앵글 | 아이소메트릭 (45도 회전, 35.264도 틸트) | 나의 아바타 중심으로 공간을 둘러보는 근접 시점 |
| 줌 범위 | 0.5x ~ 2.0x | 전체 보기 ~ 동료 확대 |
| 줌 기본값 | 1.2x (내 데스크 주변이 크게 보이도록) | 첫 진입 시 나와 주변 동료들이 보이도록 |
| 팬 | 제한적 허용 (부서 수 증가 시) | 공간이 커지면 팬 필요 |
| 회전 | 불가 (고정 앵글) | 아이소메트릭 일관성 유지 |

#### 라이팅

Versa Metaverse의 소프트 라이팅 + 보케 효과를 재현한다.

| 라이트 | 설정 | 용도 |
|---|---|---|
| Ambient Light | 강도 0.6, 색상 `#FFF5E6` (따뜻한 백색) | 전체 기본 조명, 그림자 없는 부드러운 빛 |
| Directional Light | 강도 0.8, 위치 (5, 10, 5), 색상 `#FFFAF0` | 주 조명, 소프트 쉐도우 생성 |
| Hemisphere Light | 상단 `#F5F0FF` (라벤더), 하단 `#FFF8EB` (크림) | 하늘-바닥 간접 조명, 몽환적 톤 |
| Point Light (내 데스크) | 강도 0.5, 색상 `#FFE4B5`, 거리 10 | 내 데스크 주변 조명 포인트 |

- 쉐도우: `softShadows` + `shadow-mapSize` 1024, 부드러운 그림자
- 포스트 프로세싱: 선택적으로 보케(DOF) 효과 적용 (줌 인 시 배경 흐림)

#### 환경

| 요소 | 설명 |
|---|---|
| 바닥 | 연한 크림/베이지 (`#F5EDE3`) 플레인, 부서별 영역에 고유 색상 카펫 |
| 벽/파티션 | 낮은 파티션 (캐릭터 허리 높이), 반투명 파스텔 톤 |
| 천장 | 없음 (공간 개방감을 위해 천장 불필요) |
| 배경 | 부드러운 그라데이션 스카이돔 (라벤더 -> 크림) |
| 장식 | 화분, 시계, 게시판 등 미니어처 소품 (로우폴리) |

| 작업 중 (Active) | 키보드 타이핑 (양손 교대) | 파란 기어 아이콘 회전 | 루프 (2초) |
| 대기 중 (Idle) | 커피 마시기 / 기지개 / 고개 갸웃 | 없음 | 랜덤 (5~10초마다 전환) |
| 승인 대기 (Pending) | 내 캐릭터에게 걸어와 접촉 → 승인 팝업 트리거 | 노란 봉투 아이콘 부유 + 펄스 | 루프 (3초) |
| 오류 (Error) | 당황 모션 (양팔 들어올림 + 후들후들) | 빨간 느낌표 + 번쩍 | 루프 (2초) |

| 정지 (Stopped) | 의자에 앉아서 움직이지 않음 | 회색 일시정지 아이콘 | 정적 |
| 재시도 중 | 타이핑 (빠르게) + 땀방울 | 주황 순환 화살표 | 루프 (1.5초) |

#### 3D 말풍선

- 캐릭터 머리 위에 작은 둥근 사각형 말풍선 표시
- 최대 15자, 초과 시 "..." 처리
- 표시 시간: 3초 후 페이드아웃
- 색상: 흰 배경 + 텍스트 `--text-primary`
- 용도: 상태 변화 알림 ("작업 시작!", "완료!", "도움 필요..."), Main의 짧은 인사

### 3.3 공간 구성 가이드

#### 전체 레이아웃 (공유 워크스페이스)

```
  +-------------------------------------------------+
  |                  스카이돔 배경                      |
  |   +-------------------------------------------+  |
  |   |         공유 워크스페이스 (같은 레벨)          |  |
  |   |  [내 아바타 데스크]  [Main 데스크]  [알림]    |  |
  |   +--------+----------+----------+------------+  |
  |   |        |          |          |             |  |
  |   | Part 1 |  Part 2  |  Part 3  | (빈 공간)   |  |
  |   | 부서    |  부서     | 부서     | 점선 테두리  |  |
  |   |        |          |          |             |  |
  |   | [Sub]  |  [Sub]   | [Sub]    |             |  |
  |   | [Inst] |  [Inst]  | [Inst]   |             |  |
  |   |        |          |          |             |  |
  |   +--------+----------+----------+------------+  |
  +-------------------------------------------------+
```

- **내 데스크 + Main**: 같은 레벨에서 나란히 위치. 나의 아바타가 공간 안에 존재하며, Main이 바로 옆자리에 앉아있음
- **Part 부서**: 내 데스크 주변으로 자연스럽게 펼쳐짐, 각 Part는 고유 색상의 카펫/바닥으로 구분
- **빈 공간**: 아직 생성되지 않은 부서 자리, 점선 테두리 + "Skill로 부서 추가" 힌트
- **부서 내부**: 책상 2~4개, Sub 캐릭터가 앉아있고 인스턴스 캐릭터가 옆 책상에서 작업
- **시점**: 내 아바타 데스크 근처가 크게 보이는 근접 시점, 줌아웃하면 전체 공간이 보임

#### 부서 내부 배치

```
  +---------------------------+
  |  [부서장 캐릭터]  엠블럼     |  <- 부서 이름 + 상태 라벨
  |                           |
  |  +-------+  +-------+    |
  |  | Sub A  |  | Sub B  |   |  <- Sub 팀별 책상 그룹
  |  | [팀장]  |  | [팀장]  |   |
  |  | [인스]  |  | [인스]  |   |
  |  | [인스]  |  | [인스]  |   |
  |  +-------+  +-------+    |
  +---------------------------+
```

#### 건축 애니메이션 (Part 생성 시)

1. 빈 공간에 "공사 중" 표지판 등장 (0.3초)
2. 미니 건설 캐릭터가 나타나 망치질 모션 (2초)
3. 바닥 카펫이 Part 색상으로 깔리는 애니메이션 (0.5초)
4. 파티션이 위로 솟아오름 (0.5초)
5. 책상과 의자가 "팝" 하고 나타남 (0.3초, ease-bounce)
6. Part(부서장) 캐릭터가 걸어 들어옴 (0.5초)
7. 완성 파티클 이펙트 + "프로젝트관리부 설립!" 말풍선 (1초)

총 소요: 약 5초

### 3.4 이펙트 가이드

#### 파티클 이펙트

| 이펙트 | 트리거 | 파티클 | 지속 시간 |
|---|---|---|---|
| 완료 축하 | 작업/프로젝트 완료 시 | 별 모양 + 색종이, 파스텔 5색 | 2초 |
| 부서 건축 완료 | Part 생성 완료 | 반짝이 스파클, Part 색상 | 1.5초 |
| 오류 발생 | 에이전트 오류 시 | 빨간 느낌표 + 연기 | 1초 |
| 승인 완료 | 대표가 승인 처리 시 | 초록 체크 마크 스파클 | 1초 |

- 파티클 수: 이펙트당 최대 20~30개 (성능 보호)
- `THREE.Points` + 커스텀 셰이더로 구현

#### 상태 표시 아이콘 (머리 위)

- 3D 스프라이트로 구현 (`THREE.Sprite`)
- 항상 카메라를 바라봄 (빌보드)
- 크기: 캐릭터 머리 지름의 50%
- 부유 높이: 캐릭터 머리 위 약 0.5 유닛
- 부유 애니메이션: 위아래 미세 부유 (sin 함수, 진폭 0.05, 주기 2초)

- 승인 항목: 탭하면 인라인 승인 카드 확장
- 스와이프: 좌로 스와이프 -> 빠른 승인/반려

### 5.3 반응형 브레이크포인트

| 토큰 | 너비 | 레이아웃 |
|---|---|---|
| `--bp-mobile` | < 768px | 모바일 레이아웃 (하단 네비, 3D 없음) |
| `--bp-tablet` | 768px ~ 1023px | 태블릿 (상단 네비, 3D 선택적, 분할 뷰 불가) |
| `--bp-desktop` | 1024px ~ 1439px | 데스크톱 (전체 기능, 분할 뷰 가능) |
| `--bp-wide` | >= 1440px | 와이드 (데이터 뷰 3열 그리드, 넓은 분할 뷰) |

#### 주요 반응형 규칙

- 768px 미만: 하단 내비게이션, 3D 번들 미로딩, 채팅 기본 뷰
- 768px 이상: 상단 내비게이션(워크스페이스/대시보드/설정/리소스 관리), Part 탭 표시
- 1024px 이상: 3D 워크스페이스 로딩, 캐릭터 이동 + 접촉 상호작용
- 1440px 이상: 대시보드 3열 그리드, 넓은 팝업 모달

## 6. 접근성 & 사용성

### 6.1 색상 대비

- 텍스트 대비: 최소 4.5:1 (WCAG AA)
- 대형 텍스트 (18px+): 최소 3:1
- 상태 색상: 색상만이 아닌 아이콘 + 텍스트로 이중 표현
- 프라이머리 `#7C5CFC` on 흰 배경: 대비 4.6:1 (AA 통과)
- 파스텔 배경 위 텍스트는 반드시 `--text-primary` (`#1A1523`) 사용

### 6.2 키보드 내비게이션

- **Tab 순서**: 상단 네비 -> Part 탭 -> 콘텐츠 영역 -> 하단 바
- **포커스 링**: 2px solid `#7C5CFC` + 3px offset (outline)
- **ESC**: 모달 닫기, 드롭다운 닫기, 검색 해제
- **Enter/Space**: 버튼 클릭, 체크박스 토글
- **화살표 키**: 탭 전환, 드롭다운 옵션 이동
- **채팅 단축키**: Enter 전송, Shift+Enter 줄바꿈, Ctrl+K 검색

### 6.3 에러 상태 표현

- **폼 에러**: 인풋 보더 빨간색 + 하단 에러 메시지 (아이콘 + 텍스트)
- **네트워크 에러**: 상단 배너 "서버 연결 끊김" + 재연결 시도 카운트
- **에이전트 에러**: 3D 캐릭터 당황 모션 + 채팅에서 Main이 보고 + 오류 카드
- **빈 상태**: 일러스트 + "아직 데이터가 없습니다" + 행동 유도 버튼
- **로딩 상태**: 스켈레톤 UI (파스텔 톤 펄스 애니메이션)

### 6.4 스켈레톤 UI

- 로딩 시 콘텐츠 영역에 스켈레톤 블록 표시
- 색상: `#EDE5FF` -> `#F5F0FF` 간 펄스 (1.5초 주기)
- 라디우스: 실제 콘텐츠와 동일
- 3D 씬 로딩: 프로그레스 바 + "워크스페이스를 준비하고 있습니다..." 텍스트

## 7. 다크모드 -- 야간 워크스페이스 (Phase 2 방향성)

### 컨셉

"밤의 워크스페이스 -- 창밖은 어둡고, 책상 위 조명만 따뜻하게"

Phase 2에서 구현할 야간 워크스페이스 테마의 방향성을 정의한다.

### 3D 씬 변화

- 스카이돔: 라벤더/크림 -> 짙은 남색 (`#0F172A`) + 별 파티클
- Ambient Light 강도: 0.6 -> 0.2
- 책상 조명(Point Light): 강도 0.5 -> 1.0, 따뜻한 주황 (`#FFB347`)
- 캐릭터: 야근 모션 추가 (눈 비비기, 커피 마시기)
- 창문 효과: 워크스페이스 벽에 창문 추가, 밤하늘 텍스처

### UI 색상 변환 방향

| 라이트 | 다크 | 비고 |
|---|---|---|
| `--bg-base` `#FDFBF7` | `#0F172A` | 짙은 남색 배경 |
| `--bg-surface` `#FFFFFF` | `#1E293B` | 카드/모달 배경 |
| `--bg-sidebar` `#F8F5F0` | `#162032` | 사이드바 |
| `--text-primary` `#1A1523` | `#F1F5F9` | 밝은 텍스트 |
| `--text-secondary` `#6B6478` | `#94A3B8` | 보조 텍스트 |
| `--primary-500` `#7C5CFC` | `#9B7AFF` | 살짝 밝은 프라이머리 |

### 전환 트리거

- 수동 토글 (설정)
- 시간대 자동 전환 (선택적): 일몰/일출 시각 기준
- 전환 애니메이션: 3D 씬은 조명이 서서히 어두워지는 연출 (3초), UI는 색상 전환 (500ms)
