## SB-001. 로그인 화면

- **화면명**: 로그인 화면
- **진입 경로**: 브라우저에서 ClaudeManager URL 접속
- **관련 시나리오**: SC-001
- **관련 기능**: [F059]

### 화면 설명
- 중앙에 로그인 폼이 위치한다
- 상단: ClaudeManager 로고 + "나와 AI 동료들이 함께하는 워크스페이스" 서브 텍스트
- 중앙: 비밀번호 입력 필드 (1인 사용자이므로 비밀번호만)
- 하단: "로그인" 버튼
- 배경: 파스텔 톤 그라데이션, 3D 워크스페이스의 흐릿한 실루엣 (보케 효과)

### 사용자 행동
- 비밀번호를 입력하고 "로그인" 버튼을 클릭한다

### 시스템 반응
- 비밀번호 검증 후 JWT 발급
- 로그인 성공: 화면 페이드아웃 (0.5초) -> SB-003 또는 SB-004로 전환
- 비밀번호 오류: 입력 필드 하단에 빨간 텍스트 "비밀번호가 일치하지 않습니다"
- 5회 실패 시 30초 잠금 + "잠시 후 다시 시도해주세요"

### 화면 전환
- 로그인 성공 + 최초 접속 -> SB-002 (최초 비밀번호 설정)
- 로그인 성공 + 빈 워크스페이스 -> SB-003 (빈 워크스페이스 뷰)
- 로그인 성공 + 기존 운영 중 -> SB-004 (워크스페이스 뷰 - 부서 활동)
- 서버 미연결 -> "서버에 연결할 수 없습니다" 메시지 + 재연결 버튼

### 와이어프레임

```
+--------------------------------------+
|                                      |
|      (흐릿한 3D 워크스페이스 배경, 보케)      |
|                                      |
|         +------------------+         |
|         |  ClaudeManager   |         |
|         |  나만의 AI 조직   |         |
|         |                  |         |
|         |  [..........  ]  |         |
|         |  비밀번호          |         |
|         |                  |         |
|         |  [  로그인  ]     |         |
|         +------------------+         |
|                                      |
+--------------------------------------+
```

## SB-003. 워크스페이스 뷰 (빈 워크스페이스 - 온보딩)

- **화면명**: 워크스페이스 뷰 - 빈 워크스페이스
- **진입 경로**: SB-001 로그인 성공 (최초 접속 시)
- **관련 시나리오**: SC-001
- **관련 기능**: [F008, F013, F018, F028, F059]

### 화면 설명
- **메인 영역**: 3D 카툰 렌더링 빈 워크스페이스 (Three.js + React Three Fiber)
  - 파스텔 톤 바닥 + 소프트 라이팅 + 보케 효과
  - 공유 공간: 나의 아바타(2~3등신 로우폴리 3D 카툰)가 데스크에 착석
  - 옆자리: Main(비서실장) 캐릭터 앉아있음 - 정장 + 안경, 대기 모션
  - Main 머리 위: "환영합니다!" 말풍선 (2초 후 사라짐)
  - 주변: 텅 빈 공간, 점선 테두리로 "부서 공간 예정지" 희미하게 표시
- **상단 바**: Part 탭 (현재 없음 - "아직 부서가 없습니다" 안내)
- **하단 바**: 에이전트: 1/10 | 비용: $0.00 | 헬스: 정상(초록) | 설정(톱니바퀴) | 알림(벨)
- **상단 메뉴**: 워크스페이스(활성) | 대시보드 | 설정 | 리소스 관리
- 브라우저 알림 권한 요청 팝업 (첫 진입 시)

### 사용자 행동
- Main 캐릭터에 다가가 접촉한다 -> SB-012 (팝업 모달)
- 채팅 뷰 아이콘을 클릭한다 -> SB-007 (채팅 뷰)
- 하단 바의 설정 아이콘을 클릭한다 -> SB-022 (전역 설정)
- 알림 아이콘을 클릭한다 -> SB-020 (알림 센터)

### 시스템 반응
- 알림 권한 허용 시: 이후 푸시 알림 활성화
- 알림 권한 거부 시: 대시보드 내 알림만 동작

### 화면 전환
- 채팅 아이콘 클릭 -> SB-007 (채팅 뷰 - 온보딩 대화)
- Main 접촉 -> SB-012 (팝업 모달 - Main)

### 와이어프레임

```
+----------------------------------------------+
| [전체]                           (벨) (설정)  |
+----------------------------------------------+
|                                              |
|           +-------------+                    |
|           |  내 데스크    |                    |
|           |  (대표)      |                    |
|           +-------------+                    |
|              Main                            |
|            "환영합니다!"                       |
|                                              |
|    + - - - - - - - - - - - - - - - - +       |
|    |    부서 공간 예정지 (점선)        |       |
|    + - - - - - - - - - - - - - - - - +       |
|                                              |
+----------------------------------------------+
| 에이전트: 1/10 | $0.00 | 헬스:(초록)          |
+----------------------------------------------+
|  워크스페이스* | 대시보드 | 설정 | 리소스 관리    |
+----------------------------------------------+
```

## SB-004. 워크스페이스 뷰 (부서 활동 중)

- **화면명**: 워크스페이스 뷰 - 부서 운영 중
- **진입 경로**: SB-001 로그인 / SB-007 채팅에서 워크스페이스 전환 / SC-002 부서 생성 후
- **관련 시나리오**: SC-002, SC-003, SC-019, SC-025
- **관련 기능**: [F009, F010, F011, F012, F013, F014, F018, F019, F020, F040, F044, F046, F059, F060, F061, F062]

### 화면 설명
- **메인 영역**: 3D 메타버스 워크스페이스에 부서들이 배치된 상태
  - 공유 공간: 내 데스크 + 나의 아바타
  - 옆자리: Main(비서실장) 캐릭터 - 정장 + 안경, 대기 모션
  - 부서 영역: 각 Part별 공간이 구분되어 표시
    - 부서 상단에 간판 (예: "프로젝트관리부")
    - Part(부서장) 캐릭터: 부서 중앙 책상에 착석
    - 팀 구역: Sub(팀장) + 인스턴스 캐릭터들 배치
  - 캐릭터 상태별 모션:
    - 작업 중: 타이핑 모션 + "기획 중"/"개발 중" 말풍선
    - 대기 중: 커피 마시기/기지개 모션
    - 오류: 머리 위 빨간 ! + 당황 모션
    - 완료: 기쁨 점프 모션
  - 일시정지된 팀: 반투명 회색 오버레이 + "일시정지" 라벨
  - 최상위 우선순위 팀: 별 아이콘
- **상단 바**: Part 탭 [전체] [프로젝트관리부] [재무관리부] ...
- **하단 바**: 에이전트: N/M | 비용: $XX | 헬스: 색상 | 설정 | 알림
- **상단 메뉴**: 워크스페이스(활성) | 대시보드 | 설정 | 리소스 관리
- **데스크톱**: 좌우 분할 가능 (워크스페이스 50% + 채팅 50%)

### 사용자 행동
- 캐릭터에 다가가 접촉 -> SB-012~SB-015 (팝업 모달)
- Part 탭 클릭 -> 해당 부서 공간 줌인
- 채팅 아이콘 클릭 -> SB-007
- 리포트 아이콘 클릭 -> SB-016
- 데이터 아이콘 클릭 -> SB-018
- 헬스 아이콘 클릭 -> SB-019 (시스템 헬스)
- 설정 아이콘 클릭 -> SB-022
- 알림 아이콘 클릭 -> SB-020

### 시스템 반응
- 실시간 WebSocket으로 캐릭터 상태/말풍선 자동 갱신
- 새 부서 생성 시 건축 애니메이션 (SB-011)
- 에이전트 수/비용 하단 바 실시간 업데이트

### 화면 전환
- 캐릭터 접촉 -> SB-012~SB-015 (역할별 팝업 모달)
- Part 탭 전환 -> 해당 부서 줌인/줌아웃
- 상단 메뉴 -> 각 뷰로 전환

### 와이어프레임


## SB-006. 워크스페이스 뷰 (서버 복구 애니메이션)

- **화면명**: 워크스페이스 뷰 - 서버 복구
- **진입 경로**: 서버 재시작 후 웹앱 재접속 시
- **관련 시나리오**: SC-010
- **관련 기능**: [F042, F043, F074]

### 화면 설명
- 처음 워크스페이스가 어둡게 표시 (정전 느낌)
- 조명이 하나씩 켜지는 애니메이션:
  1. 내 데스크 조명 켜짐 (0.5초)
  2. 프로젝트관리부 조명 켜짐 (0.5초)
  3. 팀 구역 조명 켜짐 (0.5초)
- 캐릭터 순차 등장:
  - Part(부서장): 기지개 모션 후 타이핑 시작
  - Sub(팀장): 커피 한잔 들고 착석

- 각 캐릭터 머리 위에 순서대로 "복구됨" 말풍선
- 하단 바에 "복구 중..." 프로그레스 바 -> 완료 시 정상 표시

### 사용자 행동
- 복구 완료 후 정상 워크스페이스 뷰로 자동 전환

### 시스템 반응
- .orchestrator/ 노트 기반 에이전트 트리 자동 복원
- 브라우저 푸시 알림: "비서실장: 서버가 재시작되어 복구가 완료되었습니다"

### 화면 전환
- 복구 완료 -> SB-004 (정상 워크스페이스 뷰)
- 일부 복구 실패 -> 해당 캐릭터에 ! 표시

- **화면명**: 채팅 뷰 - Main과 대화
- **진입 경로**: 워크스페이스에서 Main에 접촉 시 채팅 팝업 / SB-003~005에서 Main 접촉
- **관련 시나리오**: SC-001, SC-002, SC-003, SC-011, SC-013, SC-018, SC-019
- **관련 기능**: [F008, F059, F060, F061]

### 화면 설명
