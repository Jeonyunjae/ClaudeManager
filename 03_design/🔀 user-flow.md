## 1. 전체 사용자 여정

### 1.1 최초 접속 -> 온보딩 -> 일상 운영

```mermaid
flowchart TD
    START([브라우저 접속]) --> AUTH{최초 접속?}
    AUTH -->|Yes| SB002[SB-002 비밀번호 설정]
    AUTH -->|No| SB001[SB-001 로그인]
    
    SB002 --> SB003[SB-003 빈 워크스페이스]
    SB001 --> CHECK{부서 존재?}
    
    CHECK -->|No| SB003
    CHECK -->|Yes| SB004[SB-004 워크스페이스 - 부서 활동]
    
    SB003 --> SB007_onboard[SB-007 채팅 - 온보딩 대화]
    SB007_onboard --> SB009[SB-009 Skill 라이브러리]
    SB009 --> SB010[SB-010 Skill 입력 폼]
    SB010 --> SB011[SB-011 부서 건축 애니메이션]
    SB011 --> SB004
    
    SB004 --> DAILY{일상 운영 루프}
    DAILY --> MONITOR[모니터링]
    DAILY --> COMMAND[지시/제어]
    DAILY --> APPROVE[승인 처리]
    DAILY --> REPORT[리포트 확인]
    DAILY --> DATA[데이터 분석]
    DAILY --> SETTINGS[설정 관리]
    
    MONITOR --> SB004
    COMMAND --> SB007[SB-007 채팅 팝업]
    APPROVE --> SB008[SB-008 채팅 - 승인 처리]
    REPORT --> SB016[SB-016 대시보드 - 리포트]
    DATA --> SB018[SB-018 대시보드 - 데이터]

```

## 2. 주요 태스크 플로우

### 2.1 Part(부서) 생성 플로우

```mermaid
flowchart TD
    A[대표: 채팅에서 부서 생성 요청] --> B[Main: Skill 라이브러리 안내]
    B --> C[SB-009 Skill 라이브러리 표시]
    C --> D[대표: Skill 선택 + 실행]
    D --> E[SB-010 스키마 기반 입력 폼]
    E --> F[대표: 폼 작성 + 실행 클릭]
    F --> G[Main: 입력 확인 요약 채팅]
    G --> H[대표: 확인]
    H --> I[Skill execute 모드 실행]
    I --> J[SB-011 부서 건축 애니메이션]
    J --> K[DB에 Part 정보 저장]
    K --> L[.orchestrator/parts/ 폴더 생성]
    L --> M[SB-004 워크스페이스에 새 부서 표시]
    M --> N[Main: 부서 설립 완료 채팅 보고]
```

### 2.2 프로젝트 실행 플로우

```mermaid
flowchart TD
    A[대표: 채팅에서 프로젝트 지시] --> B[Main: 프로젝트 내용 확인]
    B --> C[Main -> Part: 프로젝트 전달]
    C --> D[Part: Sub 오케스트레이터 생성]
    D --> E[SB-004 워크스페이스에 팀 구역 추가]
    E --> F[Sub: 인스턴스 생성 + 태스크 분배]
    F --> G[인스턴스: 작업 수행<br>캐릭터 타이핑 모션]
    
    G --> H{승인 필요?}
    H -->|Yes| I[Sub -> Main: 승인 요청]
    I --> J[SB-005 승인 대기 상태]
    J --> K[SB-008 채팅에서 승인 처리]
    K --> L[Main -> Part -> Sub: 승인 전달]
    L --> G
    
    H -->|No| M{단계 완료?}
    M -->|No| G
    M -->|Yes| N[캐릭터 완료 점프 모션]
    N --> O{프로젝트 완료?}
    O -->|No| F
    O -->|Yes| P[Main: 프로젝트 완료 보고]
```

### 2.3 승인 처리 플로우

```mermaid
flowchart TD
    A[Sub: 의사결정 필요] --> B[Sub -> Main: 승인 요청 전달]
    B --> C[Hook HTTP POST -> 웹앱]
    C --> D[DB에 승인 요청 저장]
    D --> E1[SB-005 워크스페이스: Main 내 데스크 옆으로 이동]
    D --> E2[SB-020 알림 배지 업데이트]
    D --> E3[브라우저 푸시 알림 발송]
    
    E1 --> F[대표: 알림 확인]
    E2 --> F
    E3 --> F
    
    F --> G[SB-008 채팅 팝업 - 승인 카드]
    
    G --> H{대표 결정}
    H -->|승인| I[DB 승인 이력 저장]
    H -->|반려| J[DB 반려 이력 저장]
    H -->|수정 지시| K[코멘트 입력 -> DB 저장]
    
    I --> L[Main -> Part -> Sub: 승인 전달]
    J --> M[Main -> Part -> Sub: 반려 전달]
    K --> N[Main -> Part -> Sub: 수정 지시 전달]
    
    L --> O[SB-004 정상 워크스페이스 복귀]
    M --> P[Sub: 새 방향으로 재작업]
    N --> Q[Sub: 수정 후 재승인 요청]
```

### 2.4 오류 대응 플로우

```mermaid
flowchart TD
    A[인스턴스 오류 발생] --> B{자동 재시도}
    B -->|재시도 1~N| C[캐릭터: 빠른 타이핑 + 땀방울]
    C --> D{성공?}
    D -->|Yes| E[정상 작업 복귀]
    D -->|No| F{재시도 남음?}
    F -->|Yes| B
    F -->|No| G[캐릭터: 정지 모션]
    G --> H[SB-004 워크스페이스: 캐릭터 머리 위 빨간 느낌표]
    H --> I[Main 채팅: 오류 보고 + 재시도 실패 안내]
    I --> J[브라우저 푸시 알림]
    
    J --> K{대표 판단}
    K -->|터미널 확인| L[SB-015 팝업 모달 터미널 탭]
    K -->|재시작 지시| M[Main -> Part -> Sub: 재시작]
    K -->|모델 변경| N[Main: 다른 모델로 재시도]
    K -->|프로젝트 중단| O[Main -> Part: 프로젝트 중단]
```

## 4. 데스크톱 / 모바일 분기

```mermaid
flowchart TD
    ACCESS[브라우저 접속] --> DETECT{화면 너비}
    
    DETECT -->|1024px 이상| DESKTOP[데스크톱 모드]
    DETECT -->|768~1023px| TABLET[태블릿 모드]
    DETECT -->|768px 미만| MOBILE[모바일 모드]
    
    DESKTOP --> D_NAV[상단 내비 4탭: 워크스페이스/대시보드/설정/리소스 관리]
    D_NAV --> D_OFFICE[3D 워크스페이스]
    D_NAV --> D_DASHBOARD[대시보드]
    D_NAV --> D_SETTINGS[설정]
    D_NAV --> D_RESOURCE[리소스 관리]
    D_OFFICE -->|Main 접촉| D_CHAT_POPUP[채팅 팝업]
    
    TABLET --> T_NAV[상단 내비 4탭: 워크스페이스/대시보드/설정/리소스 관리]
    T_NAV --> T_ALL[전체 기능 - 분할 뷰 불가, 3D 선택적]
    
    MOBILE --> M_NAV[하단 내비 3탭: 채팅/알림/상태]
    M_NAV --> M_CHAT[채팅]
    M_NAV --> M_ALERT[알림 목록]
    M_NAV --> M_STATUS[상태 카드]
```

### 데스크톱 전용 기능
- 3D 워크스페이스 (Three.js + R3F)
- 채팅 팝업 (Main 접촉 시 열림)
- 분할 뷰 (워크스페이스 + 채팅)
- 팝업 모달 (캐릭터 접촉 - 대화/노트/로그/터미널)
- 대시보드 (리포트 + 비용/로그/감사이력)
- 시스템 헬스 패널
- 설정 (상단 탭)
- 리소스 관리 (상단 탭)
- 대화 흐름 트리 뷰

### 모바일 전용 기능
- 하단 3탭 내비게이션 (채팅/알림/상태)
- 상태 카드 뷰 (Part/Sub별 요약 카드)
- 인라인 승인 버튼 (채팅 내)
- 간소화된 알림 목록

### 공통 기능
- 로그인/비밀번호 설정
- 채팅 (Main과 대화 — 데스크톱: 워크스페이스 내 팝업, 모바일: 별도 화면)
- 승인 처리 (채팅 내 버튼)
- 푸시 알림 수신
