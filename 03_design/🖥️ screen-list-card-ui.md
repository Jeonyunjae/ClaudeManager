> 3D 워크스페이스는 Phase 2로 이관. 아이소메트릭 에셋 팩 구매 후 작업 예정.

## 변경 요약

### v1 -> v2 디자인 방향 변경

| 항목 | v1 (카드 그리드) | v2 (SugarCRM 컬럼 플로우) |
|---|---|---|
| 메인 레이아웃 | 세로 카드 그리드 (2~3열) | 좌->우 4단 컬럼 플로우 (계층별) |
| 계층 표현 | 부서 카드 안에 팀 리스트 중첩 | 컬럼별 분리: Main / Part / Sub / Instance |
| 관계 시각화 | 소속 경로 텍스트 | SVG 연결선 (Connection Lines) |
| 배경색 | 따뜻한 크림 (#FDFBF7) | 쿨 그레이-블루 (#F0F2F5) |
| 카드 스타일 | 12px 라운드 + 좌측 상태 보더 | 16~20px 라운드 + 소프트 그림자 + 원형 아바타 |
| 에이전트 표현 | 작은 역할 아이콘 + 텍스트 | 큰 원형 아바타 (40~56px) + 이름 + 작업 텍스트 |
| 네비게이션 보조 | PartTabs (탭 바) | 상단 아바타 행 (AgentAvatarBar) + 좌측 아이콘 사이드바 |
| 모바일 폴백 | 카드 1열 리스트 | 세로 접이식 리스트 (컬럼 -> 섹션 변환) |
| 렌더링 | 순수 React + Tailwind CSS | 동일 (변경 없음) |
| 번들 크기 | 추가 의존성 없음 | 동일 (SVG 연결선만 추가) |

### 제거되는 v1 컴포넌트
- `DepartmentGrid` -> `FlowColumnLayout`으로 대체
- `DepartmentCard` -> `DepartmentColumn` + `AgentFlowCard`로 분리
- `AgentListSection` -> 상단 `AgentAvatarBar`로 대체
- `PartTabs` -> `AgentAvatarBar` + 좌측 사이드바 필터로 대체

### 유지되는 공통 컴포넌트
- `TopNav`: 상단 네비게이션 (워크스페이스/대시보드/설정/리소스 관리)
- `BottomBar`: 하단 상태 바 (에이전트 수, 비용, CPU/MEM/DISK)
- `ChatPanel`: 우측 슬라이드 채팅 패널 (Main과 대화)
- `AgentDetailPopup`: 에이전트 클릭 시 4탭 모달 (정보/CLI 연결/로그/설정) -- SCR-OFFICE-006
- `NotificationBell`: 알림 벨 아이콘 + 배지
- `ApprovalBanner`: 승인 대기 배너 (상단 고정)
- `RecoveryOverlay`: 서버 복구 오버레이
- `SuccessToast`: 축하 토스트

## SCR-OFFICE-001. 워크스페이스 - 빈 상태 (온보딩)

- **스토리보드**: SB-003
- **URL**: `/workspace`
- **관련 기능**: F008, F013, F018, F028, F059
- **설명**: Part가 하나도 없는 초기 상태. Main 오케스트레이터만 존재하며, 첫 부서(Part) 생성을 유도하는 온보딩 화면. 컬럼 플로우는 Main 컬럼만 표시되며, 나머지 컬럼 자리에 온보딩 가이드를 배치한다.

### 컴포넌트 구조

```

  AgentAvatarBar                     -- 상단 아바타 행 (Main 아바타 1개만 표시)
    AvatarItem                       -- Main 아바타 (56px 원형) + "Main" 레이블 + 초록 상태 도트
  ContentLayout
    IconSidebar                      -- 좌측 아이콘 사이드바 (비활성 상태, 아이콘 회색)

    FlowColumnLayout                 -- 컬럼 플로우 영역
      MainColumn                     -- 컬럼 1: Main 오케스트레이터
        ColumnHeader                 -- "Main" 레이블
        MainCard                     -- Main 에이전트 카드
          AvatarCircle (56px)        -- 비서실장 아이콘 + 온라인 인디케이터(초록 점)
          AgentName                  -- "Main 오케스트레이터"
          StatusLabel                -- "대기 중 - 첫 부서를 기다리는 중"
          ActionIcons                -- 체크, 클립보드, 더보기 아이콘
          ChatButton                 -- "대화하기" 버튼
      EmptyFlowGuide                 -- 컬럼 2~4 자리: 온보딩 가이드
        DashedPlaceholderColumn (x3) -- 점선 테두리 빈 컬럼 (Part / Sub / Instance)

          IllustrationPlaceholder    -- 빈 플로우 일러스트 (SVG, 점선 화살표)
```

### 데이터 소스
- `GET /api/agents/tree` -- 에이전트 트리 (Main만 반환)
- WebSocket: `agent:status` -- Main 상태 실시간 업데이트

### 상태 관리
- `useAgentStore`: 에이전트 트리 데이터 (parts 배열이 비어있으면 빈 상태 렌더링)
- `useWorkspaceStore`: 현재 뷰 모드, 컬럼 설정
- `useChatStore`: 채팅 패널 열림/닫힘

### 반응형 전략

| 뷰포트 | 레이아웃 |
|---|---|
| 데스크톱 (>=1024px) | 좌측 사이드바 + Main 컬럼 + 빈 가이드 영역. ChatPanel 우측 슬라이드 |

| 모바일 (<768px) | Main 카드 전폭 + 가이드 전폭 세로 배치. ChatPanel 하단 풀스크린 시트 |

## SCR-OFFICE-002. 워크스페이스 - 부서 활동 (메인 뷰, 컬럼 플로우)

- **URL**: `/workspace`
- **관련 기능**: F009~F014, F018~F020, F040, F044, F046, F059~F062
- **설명**: Part(부서)가 존재하고 에이전트들이 활동 중인 메인 워크스페이스. SugarCRM Customer Journeys 스타일의 좌->우 4단 컬럼 플로우로 Main -> Part -> Sub -> Instance 계층을 시각화한다. 컬럼 간 연결선으로 관계를 표현한다.

### 데이터 소스
- `GET /api/agents/tree` -- 전체 에이전트 트리
- `GET /api/parts` -- Part 목록 + 상세
- WebSocket: `agent:status` -- 에이전트 상태 실시간 업데이트
- WebSocket: `agent:message` -- 에이전트 메시지 (카드 내 텍스트)
- WebSocket: `project:progress` -- 프로젝트 진행률 업데이트

### 상태 관리
- `useAgentStore`: 에이전트 트리, 개별 에이전트 상태
- `usePartStore`: Part 목록, 선택된 Part
- `useWorkspaceStore`: 뷰 모드 (컬럼 플로우 / 트리뷰), 정렬, 필터, 선택된 에이전트
- `useChatStore`: 채팅 패널 상태

## 부록 F. Phase 2 (3D) 복원 계획

Phase 2에서 3D 워크스페이스를 복원할 때의 전략:

1. **에셋 팩 구매**: SoWork 스타일 아이소메트릭 로우폴리 에셋 팩 (Sketchfab / Unity Asset Store)
2. **토글 전환**: `/workspace` 에 "컬럼 플로우 / 3D 오피스" 토글 버튼 추가 (IconSidebar에 배치)
3. **동일 데이터 소스**: 컬럼 플로우 UI와 3D UI가 동일한 Store/WebSocket 이벤트를 사용
4. **코드 분할**: 3D 컴포넌트는 `React.lazy`로 동적 로딩 (모바일 미로딩)
5. **점진적 전환**: 컬럼 플로우를 기본 유지하되, 3D를 옵션으로 제공
6. **3D 연결선**: SVG 연결선을 3D 공간의 파티클 트레일로 변환 (계층 관계 시각화 강화)
