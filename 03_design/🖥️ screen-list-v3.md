## SCR-01. 로그인

- **URL**: `/login`
- **접근 권한**: 비인증 상태에서만 접근
- **프로토타입**: 없음 (기존 구현 유지)

### 구성 요소

| 요소 | 설명 |
|------|------|
| 로고 | ClaudeManager 로고 + 서브텍스트 |
| 비밀번호 입력 | 단일 비밀번호 필드 (개인 서버용) |
| 로그인 버튼 | 인증 후 `/dashboard`로 이동 |
| 오류 메시지 | 비밀번호 틀림 / 잠금 안내 |
| 배경 | 그라데이션 또는 흐릿한 대시보드 실루엣 |

### API
- `POST /api/auth/login`

### Store
- `useAuthStore` (token, isAuthenticated)

## SCR-03. 대시보드 (메인 화면)

- **URL**: `/dashboard`
- **접근 권한**: 인증 필수
- **프로토타입**: `prototype/dashboard-prototype.html`
- **색상 기준**: SugarCRM Customer Journey (#E8ECEF 배경, #10141A 다크 카드)

### 전체 레이아웃

```
┌─────────────────────────────────────────────────────┐
│ TopNav (로고 | 대시보드·설정·리소스 관리 탭 | 알림·프로필)  │
├──────┬──────────────────────────────────┬────────────┤
│ Icon │ Page Header (Agent Journeys)     │ Chat Panel │
│ Side │ Avatar Bar (에이전트 아바타 행)      │ (Main과    │
│ bar  │ ───────────────────────────       │  대화)      │
│      │ 4-Column Flow                    │            │
│      │ [Main] [Part] [Sub] [Instance]   │ 승인 카드   │
│      │  카드    카드    카드     카드        │            │
│      │  ···    ···    ···     ···        │ 입력창      │
│      │ ─────────────────────────────    │            │
│      │ Bottom Section                   │            │
│      │ [활동 로그 테이블] [상태 분포 차트]   │            │
├──────┴──────────────────────────────────┴────────────┤
│ BottomBar (에이전트 N/M · 총 비용 · CPU · MEM · DISK)  │
└─────────────────────────────────────────────────────┘
```

| 요소 | 설명 |
|------|------|
| 아바타 원형 | 전체 에이전트(Main+Part+Sub+Instance) 가로 나열 |

| 컬럼 | 이름 | 설명 |
|------|------|------|
| 1 | Main | 비서실장 카드 1개 (항상 다크) |

| 3 | Sub (프로젝트) | 프론트엔드, 백엔드, 리서치 등 |
| 4 | Instance (에이전트) | UI 작업자, API 개발자, 테스터 등 |
